# Мотивация

Внедрение системы мониторинга в различных компонентах позволит значительно повысить безопасность и ускорить процесс выявления и устранения проблем. Кроме того, такой подход поможет повысить эффективность работы системы, так как мониторинг позволит выявить узкие места и оценить её устойчивость к нагрузкам. Мониторинг также будет способствовать увеличению скорости выполнения рабочих процессов благодаря снижению количества ошибок и оптимизации уже существующих процессов. В том числе, использование мониторинга даст возможность бизнесу принимать более обоснованные решения, основываясь на собранных метриках.

# Выбор методологии мониторинга

При внедрении мониторинга рекомендуется применять следующие стратегии:

* Для API-сервисов (таких как Shop, CRM, MES) следует использовать принцип «Четырех золотых сигналов», так как этот подход наиболее эффективен для сервисов, предоставляющих API.
* Для систем очередей данных, баз данных и хранения 3D-файлов будет уместен подход RED, поскольку основными показателями в этих областях являются скорость работы и количество ошибок.

# Метрики для отслеживания

* Количество dead-letter-exchange в Rabbit MQ – важно для мониторинга ошибок в очередях данных.
* RPS и RPS на пользователя для API – необходимо контролировать объем запросов для оценки нагрузки на сервисы.
* Задержка (Latency) для API – мониторинг задержек запросов даст возможность оценить производительность сервисов.
* Ошибки HTTP 500 для API – требуется отслеживание числа ошибок для анализа устойчивости приложений.
* Использование CPU для API – контроль за потреблением процессора поможет локализовать проблемы.
* Использование памяти (Memory Utilisation) для API – необходимо следить за памятью, используемой инстансами приложений, для быстрой локализации проблем.
* Объем хранилища и баз данных – нужно следить за доступным местом.
* Число одновременных сессий для API – это позволит оценить нагрузку и выявить потенциальные проблемы с незакрытыми соединениями.
  
# План действий

1. Выделить отдельный сервер для осуществления мониторинга.
2. Настроить сервер мониторинга.
3. Установить Prometheus на выделенный сервер.
4. Настроить сервисы-экспортеры для взаимодействия с Prometheus.
5. Установить и настроить Grafana для визуализации собранных данных метрик.
