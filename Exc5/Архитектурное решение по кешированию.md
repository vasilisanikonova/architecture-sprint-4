# Мотивация
Оптимизация производительности системы через настройку кеширования значительно сокращает время отклика на запросы. Это связано с тем, что данные можно быстро извлечь из кеша, в отличие от обращения к основному хранилищу. В результате снижается нагрузка на сервер, что, в свою очередь, улучшает пользовательский опыт. Более лёгкая нагрузка на системы хранения и обработки данных позволяет более рационально использовать серверные ресурсы. Внедрение кеширования в MES упростит операторам доступ к новым заказам, что поможет устранить проблему задержек при получении данных.

# Предлагаемое решение
Рекомендуется организовать кеширование информации о заказах для ускоренного отображения актуального перечня заказов для операторов MES. В качестве подхода к кешированию планируется применять серверное кеширование для MES с использованием сочетания стратегий Refresh Ahead и Write Through. Такой подход был выбран, поскольку список заказов должен оставаться актуальным для всех операторов и своевременно обновляться при изменении статуса заказов.
