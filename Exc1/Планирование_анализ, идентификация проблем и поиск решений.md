# Выявленные проблемные места системы:
* Медленная обработка заказов, оформленных через интернет-магазин;
* Низкая скорость обработки заказов, поступивших через API;
* Длительная загрузка страницы для оператора в MES;
* Использование одного инстанса для каждого приложения;
* Наличие только одного инстанса баз данных;
* Одновременная работа баз данных на запись и чтение, без реализации паттерна CQRS;
* Проведение ручного тестирования приложения;
* Ручное развертывание программного обеспечения;
* Отсутствие мониторинга для оценки уровня нагрузки;
* Недостаток трейсинга для оперативного выявления проблем;
* Неполадки с согласованностью данных в распределённых транзакциях (нет поддержки SAGA);
* Неэффективное управление запросами к микросервисам из-за отсутствия API Gateway.

# Инициативы, которые необходимы для проблем:
* Внедрить и настроить мониторинг и логирование системы;
* Внедрить кэширование для MES;
* Оптимизировать процессы CI/CD, избегая ручного развертывания;
* Приоритизировать работу с багами;
* Автоматизировать тестирование, увеличив долю автотестов;
* Расширить команду QA, добавив специалиста по автоматическому тестированию;
* Увеличить штат DevOps для настройки контейнеризации, оркестрации и автоматизации развертывания;
* Настроить репликацию баз данных;
* Реализовать поддержку CQRS для повышения эффективности работы с запросами и командами;
* Увеличить устойчивость приложения к сбоям;
* Увеличить количество инстансов приложений;
* Настроить API Gateway для балансировки загрузки между микросервисами.

# Приоритеты на ближайшие полгода:
Необходимо выявить и устранить проблемные места, приводящие к задержкам в обработке заказов. Для этого в первую очередь стоит внедрить мониторинг и логирование, повысить надёжность системы и оптимизировать работу с базами данных. Далее, ключевыми инициативами должны стать:

* Настройка мониторинга и логирования;
* Увеличение отказоустойчивости при помощи паттернов Backpressure и Circuit Breaker для снижения рисков отказов;
* Оптимизация взаимодействия с базами данных и настройка репликации данных.

В перспективе планируется расширение команды для выполнения дополнительных инициатив, таких как внедрение автоматизированного тестирования, настройка контейнеризации, реализация кэширования, увеличение числа инстансов и развитие API Gateway.
